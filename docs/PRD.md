# PRD: Trance Whale

## 1. 문서 정보

- 문서 상태: Draft
- 제품 형태: 별도 웹사이트로 제공되는 PWA(Progressive Web App)
- 대상 플랫폼: 모바일 브라우저 우선, 데스크톱 브라우저 지원
- 기본 입력: 사용자가 파일 선택기로 고른 표준 EPUB
- 웹 페이지 보조 입력 샘플: `https://www.69shuba.com/txt/48273/32028706`

## 2. 제품 개요

Trance Whale은 사용자가 합법적으로 확보해 자신의 기기에서 선택한 EPUB 또는 지원되는 외국어 웹소설 페이지를 읽고, 사용자가 제공한 Google AI Studio API Key로 자연스러운 한국어 번역을 생성하여 읽기 편한 리더 화면으로 제공하는 PWA다.

기본 흐름인 EPUB은 브라우저에서만 해제·파싱하고, 파일·추출 원문·번역·API Key를 앱 서버에 보내지 않는다. EPUB의 장과 목차는 PWA 자체 리더 UI로 재구성한다. 웹 페이지 가져오기는 보조 흐름이며, 서버가 원본 페이지에서 본문과 탐색 정보만 추출한다. 두 흐름 모두 원본 사이트를 PWA 안에서 실행하거나 DOM을 덮어쓰지 않는다.

## 3. 해결하려는 문제

- 브라우저 기본 번역은 인물명, 고유명사, 문체와 문맥의 일관성이 부족하다.
- 사용자가 매 장의 본문을 복사하여 AI 서비스에 붙여 넣는 과정은 번거롭다.
- 모바일에서 원문 사이트와 번역 도구를 오가면 독서 흐름이 끊긴다.
- 장편 콘텐츠에서는 이전 장에서 정한 용어와 말투를 계속 유지하기 어렵다.

## 4. 목표

- EPUB 하나를 선택하면 서버 업로드 없이 번역된 본문을 읽을 수 있게 한다.
- URL로 지원 웹페이지를 가져오는 보조 흐름을 제공한다.
- 원문의 문단 구조를 유지하면서 자연스러운 한국어 번역을 제공한다.
- 사용자가 번역 프롬프트를 직접 조정할 수 있게 한다.
- 이전 장, 다음 장, 목차 이동을 지원하여 연속적인 독서 경험을 제공한다.
- 별도 회원가입이나 서버 DB 없이 사용할 수 있게 한다.

## 5. 대상 사용자

- 중국어, 영어 등 외국어 웹소설을 자연스러운 한국어로 읽고 싶은 사용자
- Google AI Studio에서 본인의 Gemini API Key를 발급할 수 있는 사용자
- 모바일에서 긴 글을 지속적으로 읽는 사용자

## 6. MVP 지원 범위

### 6.1 지원 콘텐츠

- 사용자가 파일 선택기로 명시적으로 선택한 표준 EPUB 컨테이너
- OPF manifest/spine으로 장 순서를 식별할 수 있고 장 본문이 텍스트 기반 XHTML인 EPUB
- EPUB 안에서 제목, 본문 문단, spine 순서와 가능한 경우 목차를 식별할 수 있는 파일
- 공개 URL로 서버에서 접근할 수 있고 본문이 HTML 텍스트로 제공되는 웹페이지(보조 경로)
- 웹페이지 보조 경로의 MVP 우선 지원 사이트: `www.69shuba.com`
- 입력 언어 자동 감지 및 한국어 번역

### 6.2 지원하지 않는 콘텐츠

- DRM으로 보호된 EPUB 또는 웹페이지
- 이미지·Canvas·PDF 기반 본문, 고정 레이아웃 EPUB 및 텍스트로 추출할 수 없는 EPUB
- 손상되었거나 비표준 컨테이너·OPF·XHTML을 가진 EPUB
- 로그인, 구독 또는 세션 쿠키가 필요한 웹페이지
- JavaScript 실행 후에만 본문이 생성되는 페이지
- CAPTCHA나 봇 차단을 우회해야 접근할 수 있는 페이지
- 사이트 이용약관 또는 기술적 조치상 수집이 허용되지 않는 콘텐츠

## 7. 핵심 사용자 흐름

### 7.1 최초 설정

1. 사용자가 앱을 연다.
2. Google AI Studio에서 발급한 Gemini API Key를 입력한다.
3. 앱이 짧은 검증 요청을 보내 키의 유효성을 확인한다.
4. 유효한 키는 사용자 브라우저의 로컬 저장소에 저장한다.
5. 사용자는 기본 번역 프롬프트를 그대로 사용하거나 직접 수정한다.

### 7.2 EPUB을 가져와 번역해서 읽기

1. 사용자가 홈 화면에서 EPUB 파일을 선택한다.
2. 브라우저가 파일의 컨테이너·크기·항목 수·압축 해제 한도와 텍스트 기반 XHTML 장을 검증한다.
3. 브라우저가 책 메타데이터, 장 목록과 압축 EPUB Blob을 기기 IndexedDB에 저장한다. 이 과정에서 앱 서버 또는 원본 사이트에 요청하지 않는다.
4. 첫 장을 앱 내부 리더에서 열고, 클라이언트가 본문을 적절한 크기로 나누어 Gemini API에 번역을 요청한다.
5. 번역이 끝난 문단부터 리더 화면에 순차적으로 표시한다.
6. 사용자는 원문과 번역문을 전환하거나 함께 볼 수 있다.
7. 이전 장, 다음 장 또는 EPUB 목차를 선택하면 같은 책의 저장된 장을 연다.

### 7.3 웹 페이지를 가져와 번역해서 읽기(보조)

1. 사용자가 접을 수 있는 웹 페이지 가져오기 영역에서 지원되는 e-book 장 URL을 입력한다.
2. 앱 서버가 URL의 안전성과 지원 여부를 검사하고, 제목·본문 문단·탐색 링크만 추출한다.
3. 클라이언트가 추출된 본문을 Gemini API에 번역 요청하고, 리더와 웹페이지 내부 탐색으로 표시한다.

### 7.4 재방문

1. 저장된 API Key와 프롬프트를 불러온다.
2. 마지막으로 읽은 EPUB 장 또는 웹페이지 URL과 스크롤 위치가 있으면 이어 읽기 진입점을 제공한다.
3. 키가 만료되었거나 한도를 초과했다면 재설정 또는 재시도를 안내한다.

## 8. 기능 요구사항

### FR-01. EPUB 선택 및 로컬 가져오기

- 홈 화면의 기본 CTA는 접근성 있는 `.epub` 파일 선택 버튼이다. `accept` 속성은 보조 수단이며 실제 형식 검증을 대체하지 않는다.
- 앱은 사용자가 파일 선택기로 명시적으로 고른 EPUB만 읽으며, 파일·추출 원문·번역을 앱 서버로 업로드하지 않는다.
- 브라우저는 EPUB `mimetype`, `META-INF/container.xml`, OPF manifest/spine 및 navigation 문서를 검증하고, XHTML에서 제목과 텍스트 문단만 추출한다.
- 압축 파일 크기, archive 항목 수, 항목별·전체 비압축 크기, 장 수와 문단 수에 상한을 둔다. 한도를 넘는 archive는 해제하지 않는다.
- ZIP 폭탄, 손상 XML/XHTML, 빈 장, 잘못된 목차, 지원하지 않는 DRM 또는 이미지 기반 EPUB을 서로 구분한 안전한 오류로 안내한다.
- 로컬 장은 `local-epub://book/{bookId}/chapter/{index}` 형태의 앱 전용 canonical locator로 식별한다. 이 locator는 외부 HTTP URL로 취급하거나 서버 API에 전달하지 않는다.

### FR-01-1. 웹 페이지 URL 입력 및 검증(보조)

- 사용자는 `http` 또는 `https` URL을 입력할 수 있다.
- MVP에서는 허용 목록에 등록된 도메인만 처리한다.
- 잘못된 URL, 미지원 도메인, 접근 불가 페이지를 서로 구분하여 안내한다.
- 동일 URL을 다시 입력하면 가능한 경우 기존 세션의 결과를 재사용한다.
- URL 입력은 EPUB 선택과 분리된 접을 수 있는 보조 영역에 둔다.

### FR-02. 원본 페이지 추출

- 원본 페이지의 제목과 본문 문단 순서를 보존한다.
- 메뉴, 광고, 댓글, 푸터 등 본문 외 텍스트는 번역 대상에서 제외한다.
- 이전 장, 다음 장, 목차 링크를 절대 URL로 정규화한다.
- 사이트별 추출 규칙을 독립적으로 추가하거나 수정할 수 있어야 한다.
- 추출 결과가 비어 있거나 지나치게 짧으면 번역을 시작하지 않고 오류를 표시한다.
- 원본 HTML의 레이아웃, 스크립트 및 스타일은 재사용하지 않고 추출된 구조화 데이터만 클라이언트에 전달한다.
- 목차 페이지에서는 작품명과 전체 장의 제목, URL, 원본 순서를 추출한다.
- 목차가 여러 페이지로 분리된 사이트는 사이트별 추출기가 페이지를 순회할 수 있어야 한다. 단, 과도한 요청을 막기 위해 최대 페이지 수를 설정한다.

### FR-03. Gemini 번역

- Google AI Studio에서 발급한 Gemini API Key를 사용한다.
- 기본 모델은 무료 등급, 낮은 지연 시간과 번역 용도에 적합한 안정 버전인 `gemini-3.5-flash-lite`로 한다.
- 사용자는 설정에서 다음 번역 모드 중 하나를 선택할 수 있다.
  - `빠른 번역(기본)`: `gemini-3.5-flash-lite`
  - `고품질 번역`: `gemini-3.7-flash`
- 모델 선택 화면에는 모델별 상대적인 속도, 품질 및 유료 사용 시 비용 발생 가능성을 표시한다.
- `고품질 번역`은 사용자의 프로젝트 상태와 무료 할당량에 따라 무료로 동작할 수도 있으므로 유료 전용이라고 단정하지 않는다.
- 앱은 사용자의 Google Cloud 결제 설정을 대신 활성화하지 않으며, 모델 호출이 허용되지 않으면 기본 모델로 변경하도록 안내한다.
- Pro 및 Preview 모델은 비용 대비 번역 품질 향상이 검증될 때까지 MVP 선택지에서 제외한다.
- 모델 식별자는 코드에 여러 곳에 고정하지 않고 설정으로 관리한다.
- 원문 문단의 순서, 줄바꿈, 대화문 구분을 최대한 유지한다.
- 번역 결과에는 해설, 서문, Markdown 코드 블록 등 원문에 없는 내용을 추가하지 않는다.
- 응답 누락이나 문단 수 불일치를 감지하면 해당 묶음을 실패로 표시하고, 사용자가 해당 묶음만 다시 요청할 수 있다.
- 긴 본문은 문단 경계를 기준으로 분할하되, 번역 일관성을 위한 공통 지시문을 모든 요청에 포함한다.
- 사용자 프롬프트의 최상단 제목·시작 문구 지시는 장 전체에 한 번만 적용하도록 안내한다. 후속 묶음과 첫 문단 번역 이후의 재개·재시도에서는 반복하지 않도록 지시하며, 원문에 실제로 있는 중간 제목은 보존한다.

### FR-04. 사용자 프롬프트

- 앱은 자연스러운 한국어 번역을 위한 기본 프롬프트를 제공한다.
- 사용자는 기본 프롬프트에 추가할 사용자 지시사항을 입력할 수 있다.
- 사용자 프롬프트는 로컬 저장소에 저장한다.
- 빈 사용자 프롬프트도 허용한다.
- 프롬프트 변경 후 현재 장을 다시 번역할 수 있다.

### FR-05. API Key 관리

- API Key는 사용자의 브라우저에만 저장하며 앱 DB에 저장하거나 로그에 기록하지 않는다.
- API Key 입력 필드는 기본적으로 마스킹한다.
- 사용자가 키를 확인, 교체, 삭제할 수 있다.
- 클라이언트가 사용자의 키로 Gemini API를 직접 호출하여 앱 서버가 키를 중계하거나 보관하지 않게 한다.
- 오류 메시지, 분석 도구, 모니터링 데이터에 키가 포함되지 않게 한다.
- 로컬 저장은 편의 기능일 뿐 완전한 보안 저장소가 아님을 설정 화면에 안내한다.

### FR-06. 리더

- 번역문 보기, 원문 보기, 원문과 번역문 함께 보기 모드를 제공한다.
- 번역 중에도 완료된 문단부터 읽을 수 있다.
- 원문의 제목과 장 번호를 표시한다.
- 이전 장, 목차, 다음 장 이동을 제공한다. EPUB의 탐색은 같은 책의 spine 순서를 사용하며, 목차가 있으면 이를 함께 제공한다.
- 버튼이 원문 페이지 링크로 직접 이동하지 않고 앱 내부 리더 URL로 이동하게 한다. EPUB 장 URL은 `/read?book={bookId}&chapter={index}`를 사용하며 API Key, 원문 텍스트와 파일명은 URL에 포함하지 않는다.
- 글자 크기, 줄 간격, 여백을 모바일 독서에 적합한 기본값으로 제공한다.
- 모바일 리더 하단 도구막대에서 읽기 및 번역 설정을 열 수 있다. 아래로 스크롤할 때 도구막대를 숨기고 위로 스크롤할 때 다시 표시한다.

### FR-06-1. 앱 내부 목차

- EPUB 또는 원본 사이트의 전체 목차를 앱 자체 화면으로 재구성한다.
- 작품명, 전체 장 수와 읽던 위치를 표시한다.
- 원문 장 제목과 추출 가능한 장 번호를 표시한다.
- 장 번호 또는 원문 제목으로 목록을 검색할 수 있다.
- 정순과 역순 정렬을 지원한다.
- 현재 읽고 있는 장과 마지막으로 읽은 장을 강조한다.
- 수백 개 이상의 장에서도 성능이 저하되지 않도록 목록 가상화를 적용한다.
- MVP에서는 목차의 장 제목을 번역하지 않는다.
- EPUB 목차가 없거나 목차 추출에 실패해도 현재 장의 이전 장과 다음 장 이동은 계속 사용할 수 있어야 한다.

### FR-07. 진행 상태와 오류 처리

- `EPUB 가져오는 중`, `페이지 불러오는 중`, `본문 분석 중`, `번역 중`, `완료` 상태를 구분해 표시한다.
- 번역 진행률을 완료한 문단 수 기준으로 표시한다.
- 네트워크 오류와 일시적인 API 오류는 제한된 횟수만 지수 백오프로 재시도한다.
- API Key 오류, 무료 한도 초과, 안전 정책 차단, 원본 사이트 접근 실패, 저장공간 부족 및 EPUB 형식 오류를 구분하여 안내한다.
- 일부 번역이 실패해도 성공한 문단은 유지하고 실패한 부분만 재시도할 수 있다.
- 번역 요청 취소 기능을 제공한다.

### FR-08. 로컬 상태 유지

- API Key, 사용자 프롬프트, 독서 설정은 브라우저 로컬 저장소에 보관한다.
- 마지막으로 읽은 EPUB 장 또는 웹페이지 URL과 스크롤 위치를 기기 로컬에 저장한다.
- EPUB 책 메타데이터, 정렬된 장 locator와 256KB 이하 조각으로 분할한 압축 EPUB 데이터는 서로 분리한 IndexedDB record로 기기 로컬에 저장한다.
- EPUB archive, 책 메타데이터·목차·장 경로와 번역은 IndexedDB에 기기 로컬로 저장한다. EPUB 장 원문은 영구 저장하지 않고, 장을 열 때 저장된 archive에서 해당 장만 다시 추출한다. 웹페이지의 원문·번역·목차는 IndexedDB cache로 저장한다.
- 번역 캐시 키는 정규화한 원문 URL, 원문 콘텐츠 해시, 모델 식별자, 대상 언어, 기본 프롬프트 버전 및 사용자 프롬프트 해시로 구성한다.
- 같은 캐시 키가 존재하면 Gemini API를 호출하지 않고 저장된 번역을 즉시 표시한다.
- 현재 설정의 캐시가 없어도 같은 정규화 URL·원문 해시·대상 언어의 저장된 번역을 재사용한다. 모델·프롬프트 변경만으로 이미 번역한 문단을 다시 요청하지 않으며, 현재 설정으로의 재번역은 사용자가 명시적으로 요청할 때만 실행한다.
- 사용자는 현재 장을 강제로 다시 불러오고 다시 번역할 수 있다.
- 새 EPUB을 가져오기 전 `navigator.storage.estimate()`로 여유 공간을 확인하고, 사용자의 동작에서 `navigator.storage.persist()`를 요청한다.
- 장 원문·번역 cache는 최근 사용 순서로 관리하며 기본 최대 용량을 100MB로 제한한다. 브라우저 저장 공간이 부족하면 오래된 cache 항목부터 삭제할 수 있다.
- quota가 부족하면 기존 EPUB archive나 책 메타데이터를 사용자 확인 없이 삭제하지 않고 가져오기를 실패시킨다.
- 목차 캐시는 24시간 후 만료 처리하여 새 장의 추가 여부를 다시 확인한다.
- 장 본문 번역은 원문 콘텐츠 해시가 같으면 기간 제한 없이 재사용한다.
- 사용자는 앱에 저장된 모든 데이터를 한 번에 삭제할 수 있다.
- 선택한 번역 모델은 로컬 저장소에 보관하며 다음 번역 요청부터 적용한다.

### FR-09. PWA

- 지원 브라우저에서 홈 화면에 설치할 수 있어야 한다.
- 앱 셸과 정적 자산은 캐시하여 재방문 시 빠르게 표시한다.
- 웹페이지 수집과 신규 번역은 네트워크 연결이 필요함을 안내한다.
- 오프라인 상태에서는 저장된 EPUB과 장 원문, 설정 및 캐시된 번역을 열 수 있다.

## 9. 기본 번역 지시사항

시스템이 관리하는 기본 지시사항은 다음 원칙을 포함한다.

- 입력된 외국어 소설 본문만 자연스러운 한국어로 번역한다.
- 인물명, 지명, 기술명 및 경지명 등의 번역을 본문 안에서 일관되게 유지한다.
- 원문의 문체, 시점, 분위기와 높임말 관계를 보존한다.
- 문단 순서와 개수를 가능한 한 유지한다.
- 내용을 요약하거나 검열하거나 임의로 추가하지 않는다.
- 번역 외의 설명은 출력하지 않는다.

사용자 프롬프트는 위 기본 지시사항을 보완하지만, 출력 형식과 서비스 안전 규칙을 무효화할 수 없다.

## 10. 보안 및 개인정보 요구사항

- EPUB 파일, 압축 EPUB Blob, 추출 원문과 번역은 앱 서버에 전송하거나 업로드하지 않는다. 압축 EPUB Blob은 IndexedDB에만 보관한다. 번역에 필요한 텍스트는 사용자의 API Key로 브라우저에서 Gemini API에 직접 전송된다.
- EPUB 파서는 브라우저 전용으로 실행하며 HTML·CSS·이미지·스크립트·iframe·이벤트 핸들러를 저장하거나 렌더링하지 않고 텍스트 문단과 정규화된 locator만 사용한다.
- 서버 URL 수집 API는 `local-epub://` locator를 포함한 HTTP(S) 외 입력을 거부한다.
- 서버 URL 수집 기능은 SSRF 방지를 위해 허용 도메인, 프로토콜, 포트 및 리다이렉트 목적지를 검증한다.
- 사설 IP, 루프백, 링크 로컬 주소와 내부 네트워크 접근을 차단한다.
- 원본 페이지의 스크립트, iframe, 스타일 및 이벤트 핸들러를 실행하지 않는다.
- 서버 로그에는 전체 원문, 번역문, API Key를 남기지 않는다.
- 사용자가 입력한 본문은 Gemini API의 데이터 처리 정책을 적용받는다는 사실을 최초 설정 시 안내한다.
- 무료 등급 사용 시 입력 데이터가 Google의 제품 개선에 사용될 수 있음을 명확히 고지한다.
- EPUB 및 외부 사이트 콘텐츠의 이용 권한, 저작권과 이용약관 준수 책임이 사용자에게 있음을 가져오기 전에 안내한다.

## 11. 비기능 요구사항

### 성능

- EPUB 선택 또는 URL 제출 후 3초 이내에 로딩 또는 분석 상태를 표시한다.
- 번역된 첫 문단을 전체 번역 완료 전에 가능한 빨리 표시한다.
- 긴 본문 번역 시 UI가 멈추지 않아야 한다.
- 캐시된 장은 네트워크 번역 요청 없이 즉시 렌더링한다.
- 2,000개 장으로 구성된 목차에서도 스크롤과 검색 입력이 끊기지 않아야 한다.

### 접근성 및 반응형

- 360px 너비의 모바일 화면부터 정상적으로 사용할 수 있어야 한다.
- 본문 기본 글자 크기는 모바일 기준 최소 16px로 한다.
- 키보드만으로 주요 기능을 사용할 수 있어야 한다.
- 상태와 오류를 색상만으로 구분하지 않는다.

### 호환성

- 최신 Chrome, Edge, Safari 모바일 및 데스크톱 버전을 우선 지원한다.
- 특정 브라우저에서 PWA 설치가 불가능해도 웹사이트의 핵심 기능은 동작해야 한다.

## 12. 디자인 원칙

- 모바일에서 장시간 읽기 편한 밝고 단순한 리더 화면을 제공한다.
- 번역 설정은 독서 흐름을 방해하지 않도록 접을 수 있는 패널로 제공한다.
- 장식보다 본문 가독성, 진행 상태, 탐색 기능을 우선한다.
- 주요 탐색 버튼은 한 손으로 누르기 쉬운 위치와 크기로 제공한다.
- 로딩 중 레이아웃이 크게 움직이지 않도록 한다.

## 13. 성공 지표

MVP 내부 검증에서 다음을 측정한다.

- 합성 표준 EPUB fixture의 장·목차 추출 성공률 100%
- 지원 URL 본문 추출 성공률 95% 이상(보조 경로)
- EPUB 또는 추출에 성공한 웹페이지의 번역 완료율 95% 이상
- 번역 결과의 문단 순서 및 대응 관계 유지율 99% 이상
- EPUB 내부와 샘플 사이트에서 이전 장과 다음 장 이동 성공률 100%
- 모바일 360px 화면에서 EPUB 선택부터 리더 탐색까지 가로 스크롤 없이 핵심 흐름 완료

번역 품질은 중국어 원문 샘플 최소 10개 장을 대상으로 자연스러움, 의미 보존, 고유명사 일관성을 각각 5점 척도로 평가한다. MVP 목표 평균은 각 항목 4.0 이상이다.

## 14. 인수 조건

다음 조건을 모두 충족하면 MVP 핵심 흐름이 완료된 것으로 본다.

1. 사용자가 유효한 Gemini API Key를 입력하고, 홈 화면에서 EPUB을 선택할 수 있다.
2. 합성 2장 EPUB에서 제목·본문·spine 순서와 목차가 추출되고 raw HTML 또는 스크립트가 렌더링되지 않는다.
3. EPUB 파일·추출 원문·번역이 앱 서버에 전송되지 않으며, 서버 API가 local EPUB locator를 거부한다.
4. 중국어 본문이 문단 구조를 유지한 한국어로 표시된다.
5. 번역 중 진행 상태와 EPUB 형식·저장공간·번역 실패 원인을 확인할 수 있다.
6. 원문과 번역문 보기 모드를 전환할 수 있다.
7. EPUB의 이전 장, 목차, 다음 장을 앱 내부에서 이동할 수 있다.
8. 같은 설정과 원문으로 읽은 EPUB 장을 다시 열면 Gemini API를 재호출하지 않는다.
9. 새로고침·오프라인에서도 저장된 EPUB과 캐시된 번역을 다시 열 수 있다.
10. 원문이 변경되면 기존 번역을 재사용하지 않는다. 프롬프트만 변경되면 저장된 번역을 유지하고 명시적 재번역에 새 프롬프트를 적용한다.
11. 새로고침 후에도 API Key, 프롬프트와 독서 설정이 유지된다.
12. 저장 데이터 전체 삭제 후 API Key, EPUB archive, 책 메타데이터와 번역 캐시가 브라우저에서 제거된다.
13. quota 부족 시 기존 EPUB archive를 자동 삭제하지 않고 안전하게 실패한다.
14. 미지원 URL과 내부 네트워크 URL을 서버가 거부하며, 웹페이지 보조 경로는 기존 수집·내부 탐색을 유지한다.
15. 홈 화면에 설치한 PWA에서도 동일한 EPUB 핵심 흐름이 동작한다.
16. 사용자가 빠른 번역과 고품질 번역을 선택할 수 있고, 모델 변경만으로 저장된 번역을 다시 요청하지 않는다. 명시적 재번역에는 선택한 모델을 적용한다.

## 15. MVP 제외 사항

- 회원가입과 로그인
- 서버 DB 및 기기 간 동기화
- 서버에서 API Key 보관 또는 공용 API Key 제공
- 유료 결제와 구독
- 웹페이지 또는 EPUB 전체 책 일괄 번역 및 원본 파일 다운로드
- EPUB의 서버 업로드·서버 처리 또는 기기 간 동기화
- EPUB 번역 결과 내보내기
- OCR, PDF 및 이미지 기반 EPUB 본문 처리
- DRM 또는 봇 차단 우회
- 사용자가 임의 CSS 선택자를 설정하는 범용 사이트 지원
- 서버 측 번역 결과 공유 캐시
- 원본 사이트의 레이아웃, 광고, 댓글, 회원 기능 재현
- 목차 장 제목 번역

## 16. 정책 및 운영상 주의사항

- Gemini API 무료 등급은 무제한이 아니며 모델별 요청 및 토큰 한도가 적용될 수 있다.
- 무료 등급, 할당량, 모델 제공 여부는 Google 정책에 따라 변경될 수 있으므로 UI에 특정 수치를 고정해 보장하지 않는다.
- 할당량 초과 시 앱 장애처럼 표현하지 않고 사용자의 API 할당량이 소진되었음을 안내한다.
- 원본 사이트의 HTML 구조가 바뀌면 해당 사이트 추출기가 수정될 때까지 지원이 중단될 수 있다.
- EPUB 지원 범위는 텍스트 기반 XHTML 장을 가진 표준 컨테이너로 한정한다. 파일 한도는 구현 시 안전한 상수로 고정해 사용자에게 안내한다.

- 번역 요청 한 묶음의 최대 문자 또는 토큰 수
- 초기 출시 시 `www.69shuba.com` 외에 추가할 지원 도메인
